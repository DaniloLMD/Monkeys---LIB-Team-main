    
    \section{Segment Tree Beats}
    Updates:
    \begin{itemize}
        \item min(a[i],x) - range l - r
        \item max(a[i],x) - range l - r
        \item a[i]+=x - range l - r
    \end{itemize}
    Query:
    \begin{itemize}
        \item sum ai - range l-r
    \end{itemize}

    The complexity is $O(N\log^2(N))$.
